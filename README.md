# 🥠 App Biscoito da Sorte

## 📱 Descrição

O **App Biscoito da Sorte** é um aplicativo mobile desenvolvido com **React Native** que simula a experiência de quebrar um biscoito da sorte. Ao pressionar o botão “**Quebrar Biscoito**”, uma frase aleatória é exibida a partir de uma lista pré-definida, e a imagem do biscoito é atualizada para refletir a ação.

## ✨ Funcionalidades

- ✅ Exibe frases da sorte de forma aleatória.
- ✅ Altera a imagem do biscoito ao ser quebrado.
- ✅ Interface responsiva e amigável com uso de componentes do React Native.

## ⚙️ Instalação e Execução

### 🔧 Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 12 ou superior)  
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (recomendado para desenvolvimento rápido)

### 🚀 Passos para rodar o app

1. **Clone o repositório**

   ```bash
   git clone https://github.com/seu-usuario/app-biscoito-da-sorte.git
   cd app-biscoito-da-sorte
   ```

2. **Instale as dependências**

   ```bash
   npm install
   ```

3. **Inicie o aplicativo**

   ```bash
   npx expo start
   ```

4. **Visualize no seu dispositivo**
   - Escaneie o QR Code com o aplicativo **Expo Go** (disponível na Play Store e App Store)
